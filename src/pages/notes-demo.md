这是一篇用于验证「笔记模式」排版手感的演示文：正文列居中，阅读笔记浮在右侧栏，随笔以样式区隔块嵌在主栏内。边注锚定在词句上，而不是段落上。

:note-m[笔记模式]{#n1}是本博客的核心差异化排版：它把批注从正文流里挪到页边，让「读」与「批」共享同一视线平面——读到哪，批注就在哪。

:::note-m{#n1}
笔记模式的取法来自 Tufte CSS 与 gwern.net：边注与正文同视口呈现，无需跳转、无需往返。
:::

## 连续边注

连续多条边注会自动堆叠：前一条的底部决定后一条的顶部，互不重叠。这种「漂移」在 float 方案里不可控——锚点靠近时，后注会被推离锚点，这是 :note-m[float 路线的固有代价]{#n2}，M3 的 JS 碰撞定位已把它变成可调参数。

:::note-m{#n2}
float 方案零代码、稳；JS 方案（绝对定位 + 贪心碰撞）策略自由但约 80 行。边注密集的阅读场景必选后者。
:::

:::note-m{#n3}
堆叠顺序 = 源码顺序。写作纪律：边注尽量短，漂移自然小——Tufte 的应对方式。
:::

第三条边注紧跟第二条，用于验证连续堆叠的视觉节奏：:note-m[堆叠验证]{#n3}。锚点虽近，边注依序而落。

## 引用式锚定与重叠（M2）

边注不必都靠行内包裹——容器里写一句「原文引用串」，构建时在正文检索定位。上一节的段落被两条新边注的引用区间覆盖，且二者故意部分交叠：

:::note-m{#n4}
> float 方案里不可控

引用式锚定的容器写法：首块引用 = 引用串（构建时检索定位），其余内容 = 边注正文。正文侧看不到任何包裹痕迹，源文件保持干净。
:::

:::note-m{#n5}
> 不可控——锚点靠近时

重叠验证：本条的引用区间嵌在上一条的范围之内。构建产物里交叠段的 data-notes 同时含 n4 与 n5——HTML 是树，切分基本段是表达部分重叠的唯一正解。
:::

## 密集边注与左右分流（M3）

JS 碰撞定位接管后，边注尽量贴回锚点，被前一条挡住才沿链下推；一侧推得太远就分流到另一侧。下面一段连排四个锚点，是碰撞与分流的压力场景：:note-m[甲锚]{#n6}、:note-m[乙锚]{#n7}、:note-m[丙锚]{#n8}、:note-m[丁锚]{#n9}——四个锚点在正文里几乎贴在一起。

:::note-m{#n6}
甲注：右侧链的起点，贴锚点落位。边注越高，链条越容易被推起——这是分流的动力来源。
:::

:::note-m{#n7}
乙注：右链上一条的底部把本条往下推，drift 开始累积。推得越远，越可能让位给左栏。
:::

:::note-m{#n8}
丙注：若右链 drift 已超阈值而左链更空，本条会分流到左栏——两栏都在正文侧翼，视线不必长距离往返。
:::

:::note-m{#n9}
丁注：两链都占用时择 drift 小者。滚动时被推离的边注会在锚点与现位之间小幅回升；hover 中的边注则冻结不动，防止指针脱离目标。
:::

## 随笔

正文段落之间可以插入样式区隔的「随笔」。它是主栏内的块级容器，不打断阅读动线，也不进侧栏：

:::essay
这是一段随笔。它不属于正文论证，也不是边注——更像页边即兴写下的旁白。样式上用底色与竖线同正文区隔，窄屏下原位不动。
:::

随笔之后的正文继续。源语法层面，三种内容（正文 / 随笔 / 边注）在 markdown 里已可区分：普通段落、:::essay 容器、:::note-m 容器加行内锚点。

:::essay
另一段随笔，验证区隔块与后续正文的间距节奏。随笔可以连续出现而不破坏主栏动线——它始终属于正文这一侧，与边注的侧栏归属形成对照。
:::

## 脚注对照

cairn 源笔记提到：脚注可作 MVP 先验证布局手感，提升为边注是 Tufte 系经典做法。本页直接用 directive 形态，跳过了脚注中间态。

> 引用式锚定与区间分段渲染属 M2：届时边注容器内写「原文引用串」，构建时在正文检索定位成区间，天然支持多条边注的重叠范围；失配即构建警告。

回到正文收尾。若这份手感的字号、栏宽、边注密度与堆叠节奏符合预期，M2 的转换层与 M3 的碰撞布局就有了可靠的起点。
